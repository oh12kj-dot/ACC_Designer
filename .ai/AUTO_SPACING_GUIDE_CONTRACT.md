# 自動間隔と再ドラッグの契約
2026-10-23。ユーザー要求: 小粒ビーズの一括配置で隙間を詰める、配置済みも吸着/角度調整、初期ON。

- 同一node 1〜100個。間隔はAuto初期/Manual中心mm。既存の明示spacingMmはManual互換。Autoは登録済み正の有限widthMm/heightMmの配置方向への矩形投影長から、隣接2個の半幅合計（追加隙間0）を使う。直線は画像横軸方向、曲線は各位置の接線と実際の回転/補正角で評価。写真余白/実形状/実寸接触の保証ではない。未登録寸法で複数Autoは手動指定を要求する。
- guide.snap/rotateは初期true。ガイド表示は既存どおりnecklaceのみ。12 CSS px範囲、offset、実接続候補優先、全件の不足/ID/個数検証・見本/確定共有・単一UNDOを維持。pathは1本ずつ。
- 一括追加直後の自動複数選択は削除用に維持するが、その中の通常ドラッグは1個の選択へ切替えてguidePoseを適用する。Shift/一覧チェック/全選択は明示複数選択として剛体の移動を維持し、各nodeをガイドへ個別投影して潰さない。固定/実接続/Path拘束/左右連動nodeは既存canGuideMoveの除外を保つ。
- nudge/数値による微調整は既存の明示操作。ガイドのON/OFFは利用者が切替可能。既存デザインの自動整列/保存は行わない。
- 3mmビーズAutoは中心約3mm、Manual10は10mm、回転/補正/曲線/不足/欠損/ID不変、再ドラッグのON/OFF/閾値/複数移動/拘束保護、見本と確定/UNDOを検証。実ユーザーデータの試験書込なし、catalog hash保全。
- Sol Mediumを明示要求した一回の設計提案を採用（runtime実モデル/effortは公開されず確認済みとは称さない）。
