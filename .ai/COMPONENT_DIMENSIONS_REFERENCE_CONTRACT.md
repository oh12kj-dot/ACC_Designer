# 部分寸法の公表参考値

既存全件契約の意味別寸法登録を適用する。主語を明記した線径/ポスト長の7定型文、43候補から現在掲載に差分のある4件を除外し39件。現在本文と凍結原資料の数値/文を照合し、出典/品番/hashと保存する。

ワイヤー・フープ・ポスト・カラビナ・ブレスレット・リング・スティックという原文の主語を保持。ポスト長と線径、推奨する他パーツの穴径を区別する。native本体寸法/線径/穴径列、写真、接続点、販売条件、Designは変更しない。実測や接続適合とは表示しない。通常RPC/CAS、first39・正式rerun0、読戻し・全対象外行保全。購入仕様の内部ID再生成だけ記録して業務値同一を検証。掲載照合は承認差分だけ再結合する。
